In this folder you can find the codes used to study a cluster of 5 silicon atoms Si5 with Quantum Espresso.

First, 'Si5_relax.in' operates a simple realx.

Second, 'Si5_ect_convergence.in' is useful to study the convergence of the energy cutoff.

Third, running 'Si5_elec_dens.scf.in' and then 'Si5_elec_dens.pp.in' provides everything needed to visualize the electron density with XCrySden.

Lastly, 'Si5_annealing.in' operates a Simulated Annealing schedule.
