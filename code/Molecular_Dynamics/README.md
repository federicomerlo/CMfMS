In this folder you can find the LAMMPS codes used to simulate a polymer translocating through a membrane's pore.
In particular, this study aims to calculate free energy differences thanks to the Jarzynski Equality.

First, the study is based on the main code '2D_tot_production.lmp'. It outputs the necessary energy differnce.

Second, to minimize an existing structure use '2D_minimization.lmp'. You can see an example of input file in ''.

Third, to study the equilibration phase and other characteristics of the system use '2D_single_equilibration.lmp'.
